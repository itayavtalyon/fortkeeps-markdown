# fortkeeps-markdown

`FortkeepsMarkdown` is a Swift package for viewing and editing GitHub-flavored Markdown on macOS and iOS. The repo also holds **Fortkeeps Scroll**, a Mac, iPad, and iPhone app for Markdown files. Fortkeeps will use the same library for its notes.

The design lives in `design-logs/`, and the build plans live in `implementation-plans/`.
